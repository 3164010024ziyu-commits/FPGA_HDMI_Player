- `memory_top.v` 增加3位观测输出：`{refresh_error,read_error,pixel_fifo_underflow}`，直接导出实际标志。
- `hdmi_player_top.v` 增加4位观测输出 `{load_error,refresh_error,read_error,pixel_fifo_underflow}`。
