## 刷新时序观察

集成测试在第四组的首字写出后拉高 `Sdr_init_ref_vld`。当前 RTL 继续写出地址 13、14、15 的剩余三个字，然后阻止下一组启动，直到刷新信号解除。

这是实际观察到的行为：刷新信号只影响进入 WRITE 的条件，不能暂停已启动的四字写入。工程中尚无下游 SDRAM 接口时序约定，因此未将此现象判为缺陷。集成时需确认下游允许已启动的四字写入完整结束，并正确协调刷新。

这些测试验证写控制器的 RTL 数据与控制序列，采用下游在有效拍必然接收的假设。没有接入 SDRAM 器件模型，未验证器件命令时序、硬件时序收敛、板级行为或地址空间末端回绕。
