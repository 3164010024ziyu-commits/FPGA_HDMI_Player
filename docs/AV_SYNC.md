## 本版行为

- 每张 BMP 播放同名 WAV，切图时从对应配音第一个采样重新开始，不再按WAV枚举顺序选择背景音乐。
- **SW3/C6 已删除功能和顶层端口/管脚约束，拨动不影响播放**。加载图片后自动播放对应配音；原SW4仍复位。
- J1-6/H14（SW_MUTE_N）与J1-7/J14（key_in[2]）均改为**暂停**：任意一路保持低电平暂停，两路均释放为高才继续。接常开按键就是按住暂停、松开继续；接保持开关就是保持暂停。不再把音量强制设为零，原音量档位保持。
- 暂停时PCM不出队，恢复后继续下一个采样；左上角音频时间保持显示并停止推进。预读文件位置可以继续前进至缓冲区满，这不代表播放时间推进。
- 非轮播时，当前配音播完自动从头循环，音频时间随循环归零。
- J1-10/L14轮播仍按一次开、再按停；采用实际转场起点作为计时基准，每5秒开始下一次转场（视频帧边界量化）。图片提前约2秒预读；旧配音持续补充缓存，到截止前约10毫秒才切换读取上下文预读新配音，再在截止点启动转场。
- **暂停只影响音频，轮播照常**。暂停中切图后，新配音停在第一个采样，左上角时间归零并保持，恢复后从头播放新图的配音。
- 保留淡入淡出，新配音在**旧画面开始淡出**时启动，而非等待新画面完全淡入。音频短于5秒则在该图内重复；音频较长时，到切图点切换到下一配音。
- 上一张/下一张/重载、首尾循环、亮度/对比度、20档音量、FFT和TXT字幕保持。忙时仍沿用一个待处理按键请求；关闭轮播不会撤销已经接受的图像加载。

## SD卡素材

卡根目录采用相同 **8.3短文件名主体**配对，例如 `MILITARY.BMP` ↔ `MILITARY.WAV`。不能靠“第N张图片对应第N个WAV”，因为两种文件的目录顺序不保证一致。为避免中文长文件名的系统短别名差异，已为用户素材生成英文短名副本：

|---|---|---|---|
| 军事 | MILITARY.BMP / MILITARY.WAV | 161.856秒 | 原48kHz直接复制 |
| 救灾 | RESCUE.BMP / RESCUE.WAV | 255.979秒 | 原48kHz直接复制 |
| 睡眠 | SLEEP.BMP / SLEEP.WAV | 284.032秒 | 原48kHz直接复制 |
| 音乐 | MUSIC.BMP / MUSIC.WAV | 398.083秒 | 44.1kHz重采样至48kHz副本 |

原目录 `C:/Users/31640/Desktop/picture` 只读，未改名/覆盖原文件。图像均为640×480、24位BMP；WAV均为PCM、48kHz、16位双声道。重采样采用32抽头窗化sinc的160/147相位插值，不是只改文件头；DC保持、声道及1kHz基准信号已核对。输出相对原长度偏差小于一个48kHz采样。

交付 `sd_card` 目录同时含CAPTION.TXT、FONT16.BIN和字库许可，全部复制到FAT32卡根目录。之后可编辑UTF-8 CAPTION.TXT而不编译FPGA。不要同时保留同一批中文原文件和英文副本，否则会枚举成重复图片。图像枚举顺序仍按卡上目录顺序，PAIRS.json只是电脑端清单，不被FPGA解析。

缺少同名WAV或格式不兼容时，该图仍可显示、保持静音并报告音频错误（LED4锁存），不改播其他WAV。下一张正常配音可恢复，错误灯需复位清除。超慢卡无法按时准备时，系统延后转场以保持音画配对，不会用未准备好的数据强行切图。

## 实现

`wav_image_player.v` 使用独立WAV FAT上下文和现有SD扇区仲裁。图片输入完成且音频准备窗口开启后才切换文件读取上下文，预读下一段到后台PCM银行；前台银行继续输出旧图配音。自动模式在截止前约10毫秒开启窗口，避免提前2秒停止给旧PCM银行补充数据；42毫秒银行覆盖正常预读和最多一帧的截止量化等待。两个2048采样银行的名义总容量仍为4096帧，避免再复制一套大音频FIFO；物理分银行后的PCM BRAM9K由15增加到16，整机40增加到41。首采样标志随PCM一起排队，支持文件循环和暂停。

FAT新增按8字节SFN主体精确匹配，调用者在一次读取期间保持名称不变。为腾出布线空间，MBR四个分区表不再整表寄存并动态复用：接收LBA0时选择第一个0x0B/0x0C主分区，只保存其起始LBA与大小。保留原FAT32几何/边界/坏链/CRC规则。

`memory_top`与`frame_buffer_ctrl`只新增可选presentation_ready握手：写入完成后，等配音预读和轮播截止条件成立再启动淡出。SYS到memory经过两级同步；底层读写、刷新、地址算法、SDRAM IP和PLL未改。

Display检测像素域淡出级别首次下降，发toggle回SYS启动配音；音频epoch位跟随PCM穿过同一CDC队列。像素域从转场起点屏蔽旧epoch，避免播放残留旧音频。暂停时继续按48kHz发送标记为“非文件采样”的数字静音，HDMI节拍和音频包保持，计时器只统计实际播放的文件采样。原普通静音背景模式作为核心默认关闭AV_SYNC时的兼容路径保留；生产board固定启用配对模式。

`av_slideshow_ctrl.v`负责图片提前请求、音频临近截止才预读、截止时刻释放、转场重新计时、手动请求及停止。暂停输入不参与其计时。SDC仅对新控制CDC首级设路由限长，后级继续正常计时；原SDRAM相位与DQ捕获预算不变。
