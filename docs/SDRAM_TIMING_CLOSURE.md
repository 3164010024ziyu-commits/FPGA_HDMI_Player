# SDRAM DQ、FIFO、复位时序与第四字 Z 修复

更新：2026-10-28。用户授权定位、修改并验证。本轮先在隔离副本验证，保留原工程及未提交改动备份。当前配置与结论覆盖下方列出的生产源版本。

## 结论

已解决本轮定位的 DQ、FIFO 控制、复位时序问题及参考模型第四字 Z。最终 TD 布线报告整体 setup +0.104 ns、min/hold +0.031 ns，13194 项普通和例外路径检查无负裕量。实际 PLL/IP 全尺寸测试通过 7 帧、2150400 像素，8865 次刷新。尚未上板，也未完成外部 SPI/HDMI 接口时序签核。

## DQ 与第四字 Z 的共同原因

原配置为控制器 125 MHz、SDRAM 转发时钟 125 MHz / 180°。参考模型最后一字在 SDRAM 时钟沿后 5.5～10.5 ns 有效，而对应的 FPGA 采样在 +4、+12 ns，错过末字窗口；前三字在连续突发中保持到下一字输出，所以表现为每组第四字 Z，并非第四字漏写。

物理布线还要计入转发时钟的输出缓冲和输入 PAD 延迟。原 -6.565 ns 路径包含硬核 tAC 5.0 ns、输入 PAD 1.453 ns、约 4.172 ns 时钟插入差，而原静态边沿只给 4 ns。不能只把测试台改到 270°，也不能忽略 DQ 路径。

生产 PLL 改为控制器 100 MHz、SDRAM 时钟 100 MHz / 306°：周期 10 ns、转发相移 8.5 ns，均由实际厂商 PLL 模型和 TD derive_clocks 验证。参考模型末字窗口扩大为 +5.5～+12.5 ns，控制器实际有效采样位于 +11.5 ns。记录中的 DQ 输出与 Sdr_rd_en/Sdr_rd_dout 对齐，768 像素零 Z、零错值，外部复位后也重新读回正确。

加密控制器对这组数据使用 SDRAM launch 后第二个控制器上升沿，而非第一个 +1.5 ns 沿。SDC 仅给 32 位 SIP DQ 输入设置 setup=2、hold=1 的边沿关系；应用逻辑、SDRAM 写入没有多周期放宽。最大/最小各 32 条路径实际生效，未被 shadow/ignore。新增 memory capture uncertainty 0.6 ns，TD 另计默认 0.1 ns，读路径报告总预算 0.7 ns，覆盖硬核 5.0 ns 与参考模型 5.5 ns 的差异并留余量。最终 DQ 输入最差 setup +0.335 ns。

外部 EM638325 数据表的 CL3 tAC 参数亦用于交叉核对，不能据此外推合封器件的全部电气规格：[Etron 官方 Rev3.2](https://etron.com/wp-content/uploads/2022/04/EM638325_Rev-3.2.pdf)。SIP 电气默认值、厂商加密 IP 与器件模型未改。

## FIFO、仲裁与持续显示

旧路径把 Gray 转 binary、减法水位、阈值比较、仲裁、reader 状态串在一个周期，原 routed 约 -0.384 ns。现在低水位比较先在 memory 时钟寄存，仲裁下一拍使用；full 仍独立保护每次 FIFO 写入。

仅降频曾导致真实全尺寸欠载，失败实验保留。逐拍跟踪进一步发现：PREPARE/EMIT 的 read_request 空档让仲裁器在低水位时批准后台写，使读突发间隔增至 37 拍。最终实现：reader 在准备阶段及最后一个像素发出时及时提出下一组请求；以 raster_active 限定低水位保留，初次加载和光栅结束时允许写；物理 busy/active/return 全部排空并经过一个空闲拍后，可直接交接下一组。读事务仍严格四拍，刷新 pending 禁止新事务，在途事务完整收尾。真实连续读间隔缩到约 19 拍，整帧及后台写入回归通过。

## 复位和约束

原恢复时间违例位于跨时钟复位释放链的异步 SR 输入。保留异步进入、各域同步释放，只豁免 reset-release 同步链本身的 SR；链内 D 传递、输出到下游的恢复/移除继续检查。最终 2188 项 recovery/removal 检查无负值，最小 +0.031 ns。

PLL 增加只在 FPGA 配置后运行一次的 8 拍启动复位。普通 Reset_n 仍复位 memory 任务并触发重新初始化，保持 PLL 时钟连续，避免运行中复位截断 SDRAM 时钟脉冲。实际 PLL 的上电、100 次相位断言和外部复位后读回测试均通过。

TD 打包会把 .d 改成 .mi[n]，且一个物理单元可同时装第一、第二级同步寄存器。约束最终绑定跨域源网络和目标时钟，避免名字失配，也避免把相邻第二级的 hold 检查排除。四组 FIFO Gray 路径分别 5/5/12/12 条，req 1 条、ack/done 2 条、保持描述数据 19 条，8 ns 限制全部生效、无 shadow/ignore。未使用整组异步时钟 false path。

SDR_CLK_PERIOD 从 8 ns 更新为 10 ns，应用刷新周期从 1875 拍改为 1500 拍，仍为 15 µs。读写四字格式、尾包限制不变。
