## 首次验证步骤

1. 用 FAT32 卡，根目录先仅放一张 640×480、24 位、无压缩 BI_RGB BMP；无需固定文件名，当前固定选择枚举序号 0。代码不支持 exFAT/FAT16 或子目录递归。
2. 显示器连接 HDMI A。使用上面的新 `.bit` 做 JTAG 临时下载，先进行功能观察。
3. 等待 LED1（memory 初始化）和 LED2（SD 初始化）亮，再按 KEY2 加载。
4. 预期 LED3 亮、LED4 不亮，并显示方向、颜色和整幅边界都正确的图片。LED3 仅表示有有效前台帧，不能单凭它判断像素正确。
5. 按 KEY1 复位，再按 KEY2 重载，验证恢复；若 LED4 亮或黑屏，记录四灯状态、显示器是否识别输入以及 SD/BMP 信息，不将它直接归因于 SDRAM。
